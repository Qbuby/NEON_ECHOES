## Asset pipeline

Every asset is generated by a deterministic Python recipe and can be rebuilt:

```
python tools/gen_iso_tiles.py    # floors, roofs, facades, per district
python tools/gen_iso_props.py    # street furniture, signage, lamps
python tools/gen_iso_actors.py   # RIN, 4 facings x 5 animations
python tools/gen_cast.py         # 6 enemies, 3 bosses, 10 NPCs
python tools/gen_district.py     # 3 districts + 12 interiors
python tools/gen_ui.py           # HUD plates, bars, icons, minimap
```

Audio: `node <kit>/bin/make-sfx.mjs --spec game/assets/src/audio/sfx.json --out game/assets/audio`
